How My Hugo Project Is Organized

The site, the content, and the theme

May 4, 2025 · Guy Heckman · Tech · 6 min read
This post is part of the How I Built This Site series.

This site is three things working together: a Hugo project that holds configuration and layouts, a separate content repository, and a theme. Keeping them apart makes each easier to change.

The repositories

The site repository ignores content/ on purpose, because content is its own repo with its own history and its own deploy trigger.

Building locally

hugo --destination /tmp/site-preview
hugo server --buildDrafts

Deploying

Pushes to the content repo start a CodeBuild run that builds with the pinned Hugo version and syncs to S3 behind CloudFront.
