How My Hugo Project Is Organized

...or 'Why so many repos?'

A full-bleed hero with a gradient scrim keeps the title readable on any photo. The text column stays at a comfortable reading width while wide figures can break out.

One theme, one site, one deploy

Body text continues here. Links are underlined in running text, and the reading-progress bar under the nav tracks how far you have scrolled.

Repos and deploys

hugo --destination /tmp/preview

More filler text so the page is tall enough to scroll and show the progress bar moving. Hugo builds the whole site in milliseconds, which makes the content, theme and infrastructure split easy to live with.

Wrapping up

The site content lives in one repo, the theme in another, and the infrastructure in a third. Each can change on its own schedule without breaking the others.

Photos are stored on SmugMug and referenced by URL, so the repo stays small and builds stay fast. That keeps writing a post as simple as adding a Markdown file and a few image links.
