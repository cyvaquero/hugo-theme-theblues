How My Hugo Project Is Organized

May 4, 2025 · Tech · githugo

A tour of the folders, archetypes and config that keep this Hugo site tidy, and how git ties it together.

Top-level layout

Every Hugo project starts with the same handful of folders. Mine keeps content, theme and deployment scripts apart so each can change on its own.

content/ archetypes/ themes/ static/ hugo.toml

Content and archetypes

Posts live under content/post, one folder per post, with galleries referenced by shortcode rather than copied in.

Themes and config

The theme is a git submodule, so upgrades are a pull and a rebuild.

Deploying

Build, sync to the bucket, invalidate the cache. Three commands.
