    How My Hugo Project Is Organized

    May 4, 2025 · Tech · githugo
    On this pageTop-level layoutContent and archetypesThemes and configDeploying

    A tour of the folders, archetypes and config that keep this Hugo site tidy, and how git ties it together.

    Top-level layout

    Every Hugo project starts with the same handful of folders. Mine keeps content, theme and deployment scripts apart so each can change on its own.

    content/ archetypes/ themes/ static/ hugo.toml

    Content and archetypes

    Posts live under content/post, one folder per post, with galleries referenced by shortcode rather than copied in.

    Themes and config

    The theme is a git submodule, so upgrades are a pull and a rebuild.

    Deploying

    Build, sync to the bucket, invalidate the cache. Three commands.

    About

    Technologist, motorcyclist, photographer, traveler

    Hello, I am Guy. By day I build and run software; the rest of the time I am usually on two wheels, behind a camera, or both. This site is where those pieces meet.

    The photography is mostly travel and street walks: a city on foot, a long weekend, a ride that went further than planned. The writing is mostly notes to my future self about the tools I use, from Hugo and Markdown to git and a little cloud plumbing.

    Nothing here is sponsored or tracked beyond basic, privacy-respecting analytics. If something is useful, or wrong, I would like to hear about it.

    Built with Hugo and The Blues theme, hosted on S3 and CloudFront.
