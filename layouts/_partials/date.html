{{- /* A page date as shown on the site, or "Undated" when the page has none (#36). Context: a map with - date: the date (for example .Date); - format: a Go layout, default the site's params.dateFormat, else the dateFormat text ("Jan 2, 2006" in English); - time: true wraps the date in ; - undated: the text for a missing date, default the undated text ("Undated" in English; "" for none). Returns a string, or HTML when time is set. assets/js/wall.js copies a gallery's date from its first tile's caption for its group headings, so they follow params.dateFormat too. Usage: {{ partial "date.html" (dict "date" .Date "time" true) }} */ -}} {{- $d := .date -}} {{- $out := "" -}} {{- if $d.IsZero -}} {{- $out = cond (isset . "undated") .undated (T "undated") -}} {{- else -}} {{- $out = time.Format (.format | default site.Params.dateFormat | default (T "dateFormat") | string) $d -}} {{- if .time }}{{ $out = printf "%s" (time.Format "2006-01-02" $d) $out | safeHTML }}{{ end -}} {{- end -}} {{- return $out -}}
