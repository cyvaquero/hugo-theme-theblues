{{- /* A page date as shown on the site, or "Undated" when the page has none (#36). Context: a map with - date: the date (for example .Date); - format: a Go layout, default the site's params.dateFormat, else the dateFormat text ("Jan 2, 2006" in English); - time: true wraps the date in ; - undated: the text for a missing date, default the undated text ("Undated" in English; "" for none). An English site (language en or en-*) gets US English month and day names whatever its locale, as before #192 ("Sep", not en-GB's "Sept"); a site in another language gets its locale's names through time.Format. Returns a string, or HTML when time is set. assets/js/wall.js copies a gallery's date from its first tile's caption (or, for a see-all tile, its data-shown) for its group headings, so they follow params.dateFormat too. Usage: {{ partial "date.html" (dict "date" .Date "time" true) }} */ -}} {{- $d := .date -}} {{- $out := "" -}} {{- if $d.IsZero -}} {{- $out = cond (isset . "undated") .undated ((or (T "undated") (partial "t.html" "undated"))) -}} {{- else -}} {{- $layout := .format | default site.Params.dateFormat | default ((or (T "dateFormat") (partial "t.html" "dateFormat"))) | string -}} {{- $out = cond (hasPrefix (lower site.Language.Lang) "en") ($d.Format $layout) (time.Format $layout $d) -}} {{- if .time }}{{ $out = printf "%s" (time.Format "2006-01-02" $d) $out | safeHTML }}{{ end -}} {{- end -}} {{- return $out -}}
