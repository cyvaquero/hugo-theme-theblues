{{- /* Width and height of a remote photo, read at build time, so the wall and gallery images reserve their shape before they load and the masonry doesn't reflow (#7). Context: the image URL. Returns dict "w" "h", or an empty dict when the size isn't known; callers then leave the attributes out and the CSS 3:2 placeholder applies. remote-photo.html fetches the photo with resources.GetRemote, only its first 32 KB unless that doesn't give a size (#344). Hugo keeps each download in its getresource file cache (caches.getresource, by default :cacheDir/:project, kept forever), so only a photo new to the cache is fetched. A fetch that fails (offline, DNS, timeout, a server error or a refusal) is silent, so an offline build still passes --panicOnWarning. A server that answers but has no image there (HTTP 404, or not an image) is a broken photo link, so that warns (theblues-image-size); a site can silence it with ignoreLogs. Only https://photos.smugmug.com/ URLs are fetched, as hero-sizes.html does, so a build never requests another host a content author names (#255); a photo on any other host gets no size, with no request and no warning. An http:// one is never requested over the network in cleartext, where its size could be tampered with, and warns instead (theblues-insecure-photo, https-check.html, #184); the tile and gallery image get no width and height. Usage: {{ $sz := partialCached "img-size.html" $src $src }} */ -}} {{- $out := dict -}} {{- if partial "https-check.html" (dict "url" . "what" "gallery photo") -}} {{- else if findRE `^https://photos\.smugmug\.com/` . 1 -}} {{- $r := partial "remote-photo.html" . -}} {{- if not $r.Err -}} {{- with $r.Value -}} {{- if reflect.IsImageResourceWithMeta . -}} {{- $w := try .Width -}}{{- $h := try .Height -}} {{- if and (not $w.Err) (not $h.Err) (gt $w.Value 0) (gt $h.Value 0) }}{{ $out = dict "w" $w.Value "h" $h.Value }}{{ end -}} {{- else -}} {{- warnidf "theblues-image-size" "image size: %s is not an image (%s), so its tile and gallery image get no width and height" $ .MediaType.Type -}} {{- end -}} {{- else -}} {{- warnidf "theblues-image-size" "image size: %s was not found (HTTP 404), so its tile and gallery image get no width and height" . -}} {{- end -}} {{- end -}} {{- end -}} {{- return $out -}}
