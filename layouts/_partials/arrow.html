{{- /* The arrow for a previous/next link (#340). Context: "start" or "end", the side of the line the link sits on: the arrow for a link at the inline start (the previous link, "back to") or at the inline end (the next link, "more"). It points toward that side, so in a left-to-right language start is ← and end is →, and in a right-to-left language (baseof.html writes dir="rtl" under the same test) they swap. Returns HTML, so write it with no escaping step of its own, next to the link's text with no space between: {{ partial "arrow.html" "start" }}{{ $text }}. The arrow is decoration, so it comes in a span that is aria-hidden: the link's accessible name is its text, not "leftwards arrow Back to all posts" (WCAG 1.1.1, 1.3.1). The span also holds the no-break space that sets the arrow off from the text, since a plain space written outside it would be dropped at the edge of a flex item, which the pager's and the navigation's links are. Not for an attribute or a title, where the markup would show. */ -}} {{- $rtl := eq site.Language.Direction "rtl" -}} {{- if eq . "start" -}} {{- return (printf `%s ` (cond $rtl "→" "←") | safeHTML) -}} {{- else -}} {{- return (printf ` %s` (cond $rtl "←" "→") | safeHTML) -}} {{- end -}}
