{{- /* Markdown links. Only http, https, mailto and tel URLs and scheme-less paths are linked; anything else (javascript:, data:, vbscript:, or a URL that doesn't parse) renders the text without an href, as Goldmark does by default. A path that names a page or a page resource resolves to its permalink, like Hugo's built-in hook. Links to other hosts open in a new tab, and say so to screen readers: the link points aria-describedby at the one hidden notice in baseof.html (id tb-newtab, #260), so the notice is the link's description and not part of its name. A name built from the link's text would leak into a heading's name and the table of contents, which copies the heading's HTML. A reference replaces the title as the description, so a link with a Markdown title gets no reference: the notice goes after the title, in the title attribute ("Title (opens in a new tab)"), which is then the one description. That keeps the title for assistive technology without a hidden element and id per link, whose text would also land in the page's plain text and summary. rss.xml removes the reference from feed content, where the page's hidden notice doesn't exist. */ -}} {{- $href := "" -}} {{- $external := false -}} {{- $r := try (urls.Parse .Destination) -}} {{- if not $r.Err -}} {{- $u := $r.Value -}} {{- if in (slice "" "http" "https" "mailto" "tel") (lower $u.Scheme) -}} {{- $href = .Destination -}} {{- if and (not $u.Scheme) (not $u.Host) -}} {{- if strings.HasPrefix .Destination "#" -}} {{- $href = printf "%s%s" .PageInner.RelPermalink .Destination -}} {{- else if $u.Path -}} {{- $path := strings.TrimPrefix "./" $u.Path -}} {{- with or (.PageInner.GetPage $path) (.PageInner.Resources.Get $path) -}} {{- $href = .RelPermalink -}} {{- with $u.RawQuery }}{{ $href = printf "%s?%s" $href . }}{{ end -}} {{- with $u.Fragment }}{{ $href = printf "%s#%s" $href . }}{{ end -}} {{- end -}} {{- end -}} {{- else if $u.Host -}} {{- $external = ne (lower $u.Hostname) (lower (urls.Parse site.BaseURL).Hostname) -}} {{- end -}} {{- end -}} {{- end -}} {{- $title := .Title -}} {{- if and $external $title }}{{ $title = printf "%s %s" $title ((or (T "opensInNewTab") (partial "t.html" "opensInNewTab"))) }}{{ end -}} {{ .Text }} {{- /* No trailing newline: it would add a space after every link. */ -}}
